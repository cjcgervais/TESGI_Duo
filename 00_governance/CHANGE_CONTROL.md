# CHANGE CONTROL

Changes are classified by tier. Agents propose; gates decide; humans merge.

## Tier A (Kernel)
- KERNEL.md, BOUNDARIES.md, LANGUAGE_RULES.yml
- Requires explicit human approval.

## Tier B (Process)
- Templates, validators, ADRs, or evaluation suites
- Requires gate pass and human approval.

## Tier C (Client Work)
- Client artifacts, drafts, and run outputs
- Requires gate pass; human approval optional.
